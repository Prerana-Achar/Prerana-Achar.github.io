Use a PDF score

Choose a PDF in Cadence. Recognition runs on your device in the browser. There is no launcher, Python installation or local server to start.

  1. Use an up-to-date Chrome or Edge with WebAssembly JSPI support. Unsupported browsers display a message before downloading the recognition engine. MIDI import remains available.
  2. Stay online for the runtime and recognition-model downloads. The models are about 150 MB on first use and are cached when browser storage allows it.
  3. Choose a clear, unlocked printed PDF with 1–12 pages, up to 20 MB. Watch the progress below the score. Recognition can take several minutes; Reset cancels it.
  4. Review the detected pitches and rhythm before practicing. Choose the part and instrument matching the printed score.

If a PDF fails

  • Check your connection and update your browser. Content blockers may prevent runtime or model downloads.
  • Try a single clear page. Export password-protected documents as unlocked PDFs.
  • Recognition can misread notes, accidentals and rhythms. Drum notation and tablature are unsupported. Grace notes are omitted and repeats are practiced as printed.
  • If you have the original notation file, export MIDI for a more reliable practice score.

PDFs and rendered pages stay on your device. Recognition uses Sheetscan's browser port of homr; the browser downloads runtime code and models from public hosts.
