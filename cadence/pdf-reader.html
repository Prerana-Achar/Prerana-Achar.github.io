Use a PDF score

MIDI practice runs entirely in your browser. PDF scores also need the local reader running on your computer. GitHub Pages serves the website; it does not run the recognition engine.

  1. On Windows, open your downloaded cadence folder and double-click Start PDF Reader.cmd. First-time setup needs Python 3.12 and an internet connection to install the reader and its models.
  2. Keep that window open. It should say PDF reader installed.
  3. Return to Cadence and upload your PDF. Allow local-network access if your browser asks.

If the hosted page cannot connect, open the local practice page after starting the reader. It has the same practice features.

If a PDF fails

  • Check the detailed message below the score. It now distinguishes a stopped reader, an older reader, missing dependencies, and a recognition failure.
  • Use a clear, printed score with 1–12 pages, smaller than 20 MB. Password-protected PDFs need to be exported without a password.
  • If one page cannot be recognized, try that page alone. Recognition can make mistakes; review the resulting notes.
  • For an engine failure, the local .omr-cache/last-error.log file contains diagnostics. It is excluded from the copy-ready package.

On macOS/Linux, install the requirements into a Python 3.12 environment and run python recognizer/server.py. See README.md in the download for commands.
